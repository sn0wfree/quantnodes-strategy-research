## 一、实施步骤（大白话）

| 步骤 | 干什么 | 为什么 | 工期 | 刀号 |
|---|---|---|---|---|
| **1. 统一工单 + 收件口** | 所有启动方式改用同一张"工单"（谁干、干啥、插话还是排队、预算）；建统一收件口：验格式、查重、进队列。只做格式和测试，不动旧逻辑 | 现在 8 种启动方式各写各的，这是混乱的根 | 1d | E1 |
| **1b. 配置中心骨架** | 平台所有参数统一收口 ConfigHub：分层装载（默认<文件<环境变量）、按治理等级分区、敏感项隔离 | 参数散在各处必失控 | 随 E1 | ConfigHub |
| **1c. 平台数据面** | **每 session 一个自包含 SQLite**（event_log 全量永久+blobs+message）+ 全局小库（登记索引/goal/config）；现有 projector 维护 message；归档=移文件 | 事实流要有真源，会话自包含易维护，单文件天然有界 | 随 0.4 | P-1/P-2 |
| **2. 还旧债** | 修四件历史问题：调度器越权、事件推送新旧两套、三处底层反调上层、存储无统一规矩 | 地基找平，不修没法盖楼 | 4d | 0.1–0.4 |
| **3a. 防串写栅栏** | 被取消的任务，旧结果不许落库 | 现在没这保护，并发下会写脏数据 | 1d | A3 |
| **3b. 执行引擎** | 建统一"跑任务"引擎：先支持普通问答 + 带工具循环两种节点；建"重活外送通道"（回测扔子进程） | 三套引擎并存的终点就是一个 | 2–3d | A1 |
| **3c. 总调度员** | 一个会话同一时刻只干一件事；插话/排队/打断归它裁 | 现在 3–4 套控制逻辑并存 | 2d | A2 |
| **4a. 上下文独管** | 模型看到什么由一家装配，顺带管预算 | 现在四处自己拼、3 套算 token | 1.5d | A4 |
| **4b. 红线冻结** | 预算上限、停止条件等底线锁死，谁也不许改 | 自主系统的安全底线 | 1d | A5 |
| **5. 四个入口逐个接入** | 网页接口 → 定时任务 → 命令行 → MCP，逐个改走统一工单 | 做完这步"单进程网关"成形 | 4d | E2–E5 |
| **6. 上保险** | 自动检查门禁，防止以后写坏分层规矩 | 靠约定必腐烂，靠检查才持久 | 2.5d | 0.5–0.7 |
| 之后 | 研究流程改写成"可配置的图"（方法论冻结）→ 整合收尾 → 自主进化阶段 | 按既定计划推进 | — | B/C/D 系 |

## 三、后置项（已规划，不进近期）

| 项 | 内容 | 触发条件 |
|---|---|---|
| **OLAP 分析层** | 首选 **DuckDB + Parquet**（已在栈内·Windows 原生·零服务）：event_log 归档 JSONL→Parquet，`read_parquet` 直接查，与 market.duckdb 同引擎分析。**ClickHouse 只在服务化/多用户/百 GB 级时考虑**，且它替的是「分析层」，不替运行真源 | 跨研究聚合分析成为真实需求（RSI D3 统计各 tier 表现）或归档 >10GB |
| **运行真源升级** | 若迁多用户：entity/事务类换 **Postgres**（不是 ClickHouse——CH 无多语句事务、无唯一约束、更新靠异步 mutation、不保证读己所写） | 多用户/多租户需求出现 |

> 边界口径：**ClickHouse 可以替「事件扫描/流分析」这一角色，不能替 SQLite 的实体与事务角色**；blobs 永远留在文件/对象存储（CH 不是对象存储，去重只有异步最终一致）。

## 二、执行层剩余讨论

| 时机 | 要谈什么 | 一句话说明 |
|---|---|---|
| **现在** | 无 | 契约已定稿，可直接开工 |
| **做引擎前** | ① 任务图的对接设计 | 图长什么样、怎么接底层图库；**插话怎么送达正在跑的任务**——最关键的一个 |
| **做引擎前** | ② 现有循环代码的去留 | 哪些留作节点内部、哪些上交（提示词装配已定上交） |
| **做引擎前** | ③ 失败怎么办 | 一批子任务挂一个：标红跳过还是全停；重试怎么防重复 |
| **整理研究流程前** | ④ 研究流程图化 | 多阶段流程怎么改写成"一张图"（已有现成底子） |
| **整理研究流程前** | ⑤ 任务套任务 | 子图的规矩：共享约束还是各管各、最深几层 |
| **做引擎时（验证，不必讨论）** | ⑥ Windows 断网手段 | 重活子进程断网要靠防火墙规则，比一行字费事，先试 |
