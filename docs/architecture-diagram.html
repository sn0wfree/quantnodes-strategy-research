目标架构 v4 · 借鉴 OpenClaw

核心转变：1 个控制面（SessionController 唯一拥有「谁下一个能跑」）+ N 个可换执行面（AgentRuntime 协议）+ 上下文平台独占（ContextHub 装配与预算）+ 不变量层（Tier 0 冻结）｜研究方法论层原样保留

目标态（控制面 / 上下文 / 执行面） 协议 / 契约 / 研究域 待建（Director / RunContext / InvariantLayer） ②–⑥ 待解决问题

与现状的差别（对照 v3 → v4）

面现状（v3）目标（v4）
控制面3–4 套并存：SessionService / StudyRunner / SwarmRuntime / Workflow1 套：SessionController 唯一拥有 turn 准入；StudyLoop 降为 research runtime
执行面AgentLoop / phase_engine 硬编码在编排层，无契约AgentRuntime 协议 + 选择器 + 声明式回退；3 个实现（ReAct/Research/Dag）
上下文4 PromptBuilder + 5 injector 各自拼；validate() 死契约ContextHub 独占装配与预算；provider 只取数+标注；缓存边界 + 分层预算 + 归属
运行期环境预算/事件/追踪/取消三套并行RunContext 唯一实现，三处共用
并发正确性无 write fence（取代的 run 可提交陈旧数据）SessionController 内置 activeRunId 认领 + 提交校验
不变量散落在各模块的约定不变量层（Tier 0 冻结，插件无权覆盖）
