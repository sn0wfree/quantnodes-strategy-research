## Step 实现

### DefaultProgressStep（复用 AgentLoop 状态）

```python
def bind_agent_loop(self, loop): self._loop = loop

def record_hash(self, ctx, hash_value):
    loop._recent_hashes.append(hash_value)
    window = loop.no_progress_window
    if len(loop._recent_hashes) > window:
        loop._recent_hashes = loop._recent_hashes[-window:]

def is_no_progress(self, ctx):
    return self._loop._detect_no_progress()
```

### DefaultResilienceStep（走 circuit_breaker）

```python
def is_open(self, ctx):
    cb = getattr(self._loop, "_circuit_breaker", None)
    return cb is not None and cb.is_open()
```

## `_call_step` 统一错误隔离

```python
async def _call_step(self, step, ctx, *, async_mode):
    try:
        result = step.execute(ctx, async_mode=async_mode)
        if inspect.isawaitable(result):
            return await result
        return result
    except Exception as exc:
        logger.warning("step %s failed: %s", step.name, exc)
        ctx.should_stop = True
        ctx.stop_reason = f"step_{step.name}"
        return ctx
```
