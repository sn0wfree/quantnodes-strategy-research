## 一、研报说了什么: 三个框架一条线

三个框架按首次公开时间递进, 搜索单元逐级放大:

```
AlphaAgent (2025.02)          RD-Agent (2025.05)             QuantaAlpha (2026.02)
一轮 = 一次循环                一轮 = 一次研发闭环              一次完整运行 = 一条"研究轨迹"
Idea/Factor/Eval 三模块        假设→实验→代码→回测→反馈         轨迹池 + 选择/变异/交叉
(DSL表达式, 封装工具)          (微软开源, Qlib场景)            (复用RD-Agent底层 + 演化控制器)
      │                              │                              │
      └──── 闭环 ──────────────► 闭环+模块化+历史经验 ──────►  闭环之上再加"演化层"
```

| 维度 | AlphaAgent | RD-Agent (微软) | QuantaAlpha |
|---|---|---|---|
| 定位 | LLM+正则化探索, 对抗alpha衰减 | 通用自动化研发框架 (因子/模型/文献复现) | 轨迹级自进化因子挖掘 |
| 组织方式 | Idea/Factor/Eval 三模块逻辑分工 (非三个独立智能体) | Research+Development 两段, Qlib因子场景五步闭环 | 底层复用RD-Agent, 上层加演化控制器 |
| 因子表达 | DSL (预定义算子组合, 不生成Python) | 生成Python代码 (CoSTEER进化式代码生成) | 生成Python代码 + 语义一致性门 + AST冗余度量 |
| 搜索机制 | 循环迭代 | 单链路循环, 历史实验反馈 | 多条轨迹并行, 遗传操作 (选择/变异/交叉) |
| 入库判据 | RankIC/多空/换手综合评价 | 新因子加入特征集后能否改善**整体**模型表现 (SOTA判据) | 验证期准入 + 池内相关性去重 + 贪心RankIC |

研报的定位判断 (摘要原话): AI Agent 现阶段更适合**拓宽研究广度、提高实验效率**, 候选因子的**最终入库仍需研究员把关**; 实际应用应加强样本外检验、边际贡献评估、跨session相关性控制、经济逻辑审查和风险暴露分析。

### 研报自己的实证 (RD-Agent, 不是QuantaAlpha)

值得注意: 研报实证选的是 RD-Agent 而非 QuantaAlpha (后者2026年2月才公开, 报告9月发表但未跑它), 对 QuantaAlpha 只有一句评价: "拓宽探索空间的同时也增加了计算与存储开销"。

实证设置: A股, Alpha20基准特征 + LightGBM, 预测未来5日收益, 中证1000基准, 训练2016-2022 / 验证2023-2024 / 测试2025-01~2026-07; 数据在价量之外按PIT对齐加了三大报表字段; 本地部署 qwen3.8-27b 做生成 + qwen3-embedding-0.6b 做检索。

结果要点 (这是全篇研报最有含金量的部分, 是对AI因子挖掘的期望管理):

1. 30轮迭代**只有第12、13轮更新了SOTA** (30个可用因子)。IC/RankIC 确实随迭代抬升 (Alpha Base RankIC 5.71% → 后期普遍5.8-6.3%), 但年化收益、信息比率、最大回撤**波动巨大且不单调** (信息比率从0.08到0.90乱跳)。
2. 因子层面的结论更扎心: 35个因子里全区间RankIC最高的"特质波动率反转"因子 (Lag1IdioVol20WinsorNeg, 剔市场收益后20日特质波动取负缩尾), 全区间RankIC 7.42% / 样本外7.04%, 分组单调漂亮, 但**多空组合2025下半年大幅回撤**。
3. 跨session挖了159个因子: 大多数两两低相关 (说明LLM确实能产出不同信息), 但按0.7相关切分仍有**多个小簇, 名字和表达式不同、信息其实一样**; 官方默认去重阈值0.99过于宽松。
4. Barra风格回归: 多数因子线性暴露弱, 但**低线性暴露≠干净**——乘积、分段、滚动窗口这类非线性构造, 线性回归根本排除不了风格暴露。
5. SOTA组合2026年3月后超额明显回撤, 与科技风格走强、分化加剧重合——模型对风格切换敏感。

一句话: **IC会涨, 策略不一定涨; 因子好看, 组合不一定好看; AI广度是真广度, 深度和稳定性还是要人来兜底。**

## 二、QuantaAlpha 深研 (重点)

### 2.1 是谁做的

上海财经大学 AIFin 实验室 (张硕/朱尤木等) 联合清华、北大、中科院自动化所、CMU、港科大团队, 2026-02-06 挂 arXiv (2602.07085), 代码 MIT 开源。目标是"输入研究方向, 其余自动运行"。工程上直接**复用 RD-Agent 的底层研发流程**, 自己的贡献集中在演化层。

### 2.2 核心思想: 把"进化对象"从因子公式升级为完整研究轨迹

```
遗传规划 (传统)          : 进化对象 = 因子表达式 (公式树)
AlphaAgent/RD-Agent     : 进化对象 = 无 (单链路循环, 没有种群)
QuantaAlpha             : 进化对象 = 研究轨迹 τ = (假设 → 语义描述 → 表达式 → 代码 → 回测结果)
                          适应度 R(τ) = L(因子, 收益) − λ·复杂度惩罚
                          优化对象 = "生成轨迹的策略", 不是单个因子
```

论文自述要治三个病:
1. **脆弱可控性**: 回测反馈本身是噪声, 直接拿它当适应度会诱导LLM朝伪相关漂移;
2. **可信度有限**: 生成的因子说不清来路, 无血统可溯;
3. **探索受限**: 在局部邻域过采样, 挖出来的全是拥挤方向的变体。

### 2.3 架构: 四个组件

```
研究方向
   │
   ▼
┌─[A] 多样化规划初始化 ──────────────────────────────────────┐
│  以Alpha158种子按低相关分组, 起10个并行方向                  │
│  要求语义+结构互补: 不同信号源 / 不同时间尺度 / 不同机制类型   │
└──────────────┬───────────────────────────────────────────┘
               ▼
┌─[B] 可控因子实现 (每条轨迹的"一轮研发") ────────────────────┐
│  假设h → 结构化语义描述d → 符号表达式f(AST中间表示)          │
│        → 可执行代码c → 回测                                 │
│  ★ 语义一致性门: LLM检查 h-d-f 对齐 + f-c忠实,              │
│    不一致打回重写, 直到通过或预算耗尽                        │
│  ★ 三道约束门:                                             │
│    复杂度 = α1·符号长度 + α2·自由参数数 + α3·log(1+特征数)   │
│    冗余   = AST最大公共子树 (和已有因子共享子树过大→拒绝重写)  │
│    输出级 : 验证期(2021)因子值|相关|超阈值→只留RankIC高者     │
└──────────────┬───────────────────────────────────────────┘
               ▼
┌─[C] 自进化循环 ───────────────────────────────────────────┐
│  Mutation : 自反思定位轨迹中的"次优决策节点",               │
│             冻结前缀, 只重写局部段 (换窗口/换变量/加约束)     │
│  Crossover: 按奖励挑父代轨迹, 重组高奖励片段               │
│             (假设模板/构造模式/修代码的行为)                 │
│  循环: Original → Mutation → Crossover → Mutation → …     │
└──────────────┬───────────────────────────────────────────┘
               ▼
┌─[D] 最终因子池 ──────────────────────────────────────────┐
│  贪心、只用2021验证期选因子:                               │
│  候选按RankIC排 → 逐个检查与池内因子|相关|<0.7 → 准入       │
│  池大小 ≤ 挖掘总量的50%                                    │
└──────────────────────────────────────────────────────────┘
```

三道约束门是全文工程含量最高的部分, 逐条说:

- **语义一致性门** (对治"病1"): 不让LLM直接拿回测数字自我强化, 而是先保证"想法、描述、公式、代码"四层互相说得通, 再谈表现。这本质上把"骗回测"的空间压缩到代码执行层以下。
- **复杂度约束** (对治病1+3): 显式惩罚符号长度、自由参数、特征数, 防止LLM靠堆砌拟合。公式为 `C(f)=α1·SL(f)+α2·PC(f)+α3·log(1+|F_f|)`。
- **冗余控制** (对治病3): 两级——AST层面算与已有因子的最大公共子树, 子树过大直接拒绝生成; 输出层面在2021验证集上算因子值相关性, 超阈值只留RankIC高的那个。注意它去重用的是**因子值相关性**, 不是研报批评RD-Agent的0.99阈值那种"表达式相近才算重复"。

### 2.4 实验数字 (GPT-5.2为主力模型)

设置: 中证300成分股, 训练2016-2020 / 验证2021 / 测试2022-2025.12.26; 下游LightGBM, TopkDropout组合 (留50只、每期换5只); 成本双边按买0.05%/卖0.15%; 预测目标 y_t = close[t+2]/close[t+1] − 1 (信号在t日收盘, 用t+1到t+2的价格段——**结构上与本项目open口径的执行配对是同构的**, 都跳过了"信号次日"不可执行的时段, 只是价格锚一个用收盘一个用开盘)。

| 框架 | IC | RankIC | 年化超额 | 信息比率 | 最大回撤 |
|---|---|---|---|---|---|
| AlphaAgent | 0.0347 | 0.0373 | 1.11% | 0.2467 | 13.89% |
| RD-Agent | 0.0286 | 0.0332 | 3.58% | 0.4866 | 16.76% |
| **QuantaAlpha** | **0.0472** | **0.0459** | **4.68%** | **0.6453** | **11.80%** |

消融 (去掉某组件后的退化):

| 去掉 | IC变化 | 年化超额变化 | 说明 |
|---|---|---|---|
| Mutation | −0.0079 | −1.26% | **贡献最大**——局部定向修比全局重组更值钱 |
| Crossover | −0.0060 | −0.41% | 次之 |
| 一致性验证 | −0.0045 | −0.50% | 有真实贡献, 不是摆设 |
| 复杂度约束 | −0.0030 | −0.95% | 去掉后回撤恶化 +2.31%, 防过拟合主力 |
| 冗余控制 | −0.0024 | −0.11% | 主要是省了重复劳动 |
| 多样化规划 | +0.0010* | −0.72% | *IC反升但策略层掉, 且回撤+1.62%——规划多样性的价值体现在组合层不在单因子层 |

其他关键发现:

- **进化轮数收益递减**: 15轮迭代实验里, 第11-12轮 (约350个累计因子) 是最优权衡点, 之后新因子开始引入冗余信息, 回撤反而变差。**不是轮数越多越好**——与研报RD-Agent实证"30轮只有2轮SOTA"互为印证。
- **跨种子稳健**: 3组随机种子, IC标准差0.0021 (变异系数4.64%)。
- **统计显著性**: 日频IC的t值7.93 (DeepSeek配置), 测试期966个交易日正IC天数占比>60%。
- **成本不敏感**: 交易成本加倍后仍稳, 原因是TopkDropout每期只换约10%持仓。
- **跨市场零样本迁移**: 中证300挖的因子直接搬到中证500 (+40.28%四年累计超额) 和标普500 (+19.1%), 只用OHLCV+vwap六列, 截面rank归一化消除市场规模差异。说明学到的是**可迁移的构造模式**, 不是对单一市场的过拟合。
- **alpha衰减诊断** (最有意思的一节): 2023年A股风格切换 (大盘核心资产→小盘题材), 基线框架的因子集体失效, QuantaAlpha靠"隔夜跳空、波动结构、趋势质量"类信息通道的因子保持IC。论文的归因是: 胜利不来自拟合了某个市场状态, 而来自**维持了因子群的信息多样性**——拥挤方向死了, 冷门通道还活着。
- **血统可追溯案例**: "机构动量"因子由两条父轨迹交叉而来——父代A"散户投机动量" (散户占比变化×动量) + 父代B"机构持续动量" (机构持股变化×动量), 融合假设是"机构持续流入放大动量持续性"。每个入库因子都能画出家谱。

- **成本账**: 10个并行方向+5轮进化 (1初始+4变异/交叉轮), 一次完整运行约20小时、约180万tokens (对照: AlphaAgent 150万, RD-Agent 230万), 无需本地GPU, 全程API调用。

### 2.5 诚实的局限 (论文自己的 + 我们补的)

论文自认:
1. 演化搜索本质是启发式, 无收敛保证;
2. 全部实证在股票截面日频, 未验证期货/高频;
3. 依赖回测反馈做适应度, 回测噪声的根子还在, 只是被一致性门压低了。

我们补四条:
1. **年化超额4.68%、IR 0.645本身并不惊艳**——这是满仓多头组合对指数的超额, 与本项目语境的绝对收益不可比; 它的卖点是IC和回撤改善幅度相对基线, 不是绝对收益水平。
2. **进化收益的很大一块来自"多试"**: 10方向×5轮≈几十次完整研发循环, 每次循环都有回测选择性。跨种子方差小只说明过程稳定, 不排除整体的回测选择偏差 (论文的2021验证期准入+0.7去重是缓解, 不是消除)。这正是研报说的"入库需研究员把关"的另一种说法。
3. **"跨市场迁移"仍是股票截面内的迁移** (沪深300→中证500→标普500都是股票截面), 不构成跨资产类别证据。
4. 券商研报自己也没有实证QuantaAlpha (只实证了RD-Agent), "演化层值不值这个钱"目前**没有独立第三方复现**, 只有论文自证+消融。

## 三、对本项目的映射 (商品CTA × 这套AI挖掘框架)

先说结论: **不建议直接引入任何框架跑生产**, 建议吸收其工程纪律; 演化控制器可以作为一个候选预研线, 成本不低、预期收益存疑。

### 3.1 适用性判断

| QuantaAlpha的部件 | 对本项目 | 判断 |
|---|---|---|
| 轨迹级演化 (选择/变异/交叉) | 我们因子挖掘是人工+预注册制, 不是无主搜索 | **暂缓**。本质差异: 他们优化"搜索策略", 我们约束"每条入库路径"。若引入, 相当于把zoo因子库的扩展交还给机器搜, 与预注册纪律冲突, 除非把演化也预注册 |
| 语义一致性门 (想法-描述-公式-代码四层对齐) | 对治"代码实现与假设不一致" | **直接可抄**, 零框架成本。我们人工挖因子时同样会犯"实现漂移" (写着写着和预注册假设不是一回事), 可作为因子入库检查单的一项 |
| 复杂度约束 (符号长度/自由参数/特征数惩罚) | 对治过拟合, 与BIC思想同源 | **直接可抄**为zoo入库规则: 新因子登记符号长度与自由参数数, 超阈值需额外说明 |
| AST公共子树/因子值相关性去重 | 我们的因子库去重目前靠人工+相关矩阵 | **可抄**: 入库前算与库内全部因子的验证期值相关性, 阈值可比照0.7 |
| "验证期准入+贪心去重"的池维护 | 我们有"已测未启用清单" | 理念一致, 把隐式做法显式化为规则 |
| 隔夜跳空/波动结构/趋势质量的信息通道分类法 | 商品期货有对应物: 夜盘缺口、期限结构、趋势质量 | **有启发的诊断框架**: 给zoo因子库按信息通道打标签, 衰减时看是哪条通道死了 (比宏观门控那五类全灭的教训更细) |
| 跨市场零样本迁移测试 | 我们有43品种池/12品种精简池 | **可抄为稳健性检验**: zoo因子在小池子上的表现衰减度, 当作"过拟合度"的一个免费代理指标 |
| 下游SOTA判据 (单因子弱但边际贡献正即有效) | 与我们"卫星边际改善"评判标准同构 | 已有, 印证现有做法 |

### 3.2 成本与风险 (若真要试演化线)

- 直接跑QuantaAlpha仓库不可行: 数据栈是Qlib+A股, 与我们的商品期货库完全不同; 要跑就得把QlibFactorRunner换成我们自己的数据接口+回测栈, 工程量约等于重写一半。
- 折中路径 (如果要试): 不搬框架, 只在zoo因子库上实现"轻量演化控制器"——用我们现有回测, LLM基于已测因子提出变异/交叉方向, 人工预注册批次后执行。这仍是预注册制, 只是提案环节机器化。
- 预期收益要打折: 研报RD-Agent实证30轮只有2轮真改善; QuantaAlpha自己的收益也集中在"从无到有"的初始广度。我们的zoo已经有39个冻结因子+三大族收官 (CS动量/TS动量/CARRY), **剩余增量空间未知**, 演化搜索大概率产出的是已测方向的变体 (他们的冗余控制正是为这个病设的)。
- token成本参考: 他们一次完整运行180万tokens; 挪到CTA数据栈上, 轨迹数×轮数×代码重试的乘积只会更多。

```
              ③ 信息通道标签体系 (衰减归因用, 不做择时门控)
        │
        └── 暂缓但可预注册的贵东西: 轻量演化控制器 (zoo扩展器)
```

## 四、结论与待拍板事项

1. **研报层面**: 三框架是同一思想的两次放大 (闭环→模块化→演化); 研报实证的价值不在框架评测, 而在给AI因子挖掘**定了期望的锚**——广度工具, 深度靠人。
2. **QuantaAlpha层面**: 方法论上是把遗传规划的对象从"公式"换成"研究轨迹", 真正的护城河不是演化本身, 而是三道约束门 (一致性/复杂度/冗余) + 血统追溯; 数字上的胜出集中在IC和回撤, 绝对收益平平; 无独立第三方复现。
3. **行动建议** (2026-09-21 已拍板: 采纳三件便宜货, 见第五节落地记录; 演化线维持暂缓):
   - 采纳: 把 3.3 图中三件便宜货写进 zoo 因子库的入库纪律 (一次预注册, 零框架成本);
   - 暂缓: 演化控制器预研线, 除非明确要在2027真OOS前扩充zoo且接受预算;
   - 反对: 直接部署任何框架对接生产数据栈。
4. 风险提示: 上述论文数字均为其作者在A股历史数据上的自证, 未来失效风险; 研报为卖方观点。
